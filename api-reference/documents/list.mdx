---
title: 'Lists all documents'
openapi: 'GET /documents'
---

Filter with `type=payslip` or `type=bank_statement` (case-insensitive). Omit `type` to return all documents.

Payslip documents include `trust_score`, `trust_analysis`, and `pdf_metadata`. Bank statement documents leave those fields null. `file_contents` on the list endpoint is a download path, not the file bytes. See [Doc Scan](/doc-scan).

---
title: 'Get ONS expenditure'
openapi: 'GET /expenditure/{user_id}/ons'
---

Monthly cost of living and housing estimates from the Teal V3.0 ONS Family Spending model (table A6).

Cost of living is age-adjusted. Housing is region-adjusted from the user's first postcode. Age is calculated as of the last day of each month.

`404` returns `{ "errors": [...] }` with one string per missing input (`date_of_birth`, `post_codes`, payroll periods, or region for prefixes such as GY/IM).
